# Writing prose

Use the `humanizer:humanizer` skill on prose written for a human reader, after
drafting it and before showing it to me:

- code comments and doc blocks
- README, docs and help articles
- PR descriptions and commit message bodies

Skip it for a comment of a line or two, log lines, test names and error strings.
The skill removes AI tells; it does not shorten. Repo rules on comment length and
tone still win where they exist.
